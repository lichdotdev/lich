一个任务，一个 worktree，一个会话。输入 issue 编号，lich 会用 issue 标题给分支命名，从你选的基础分支创建 worktree，再把这个 issue 作为第一条 prompt 交给智能体。

    
Claude Code、Codex、opencode 并排跑。每个面板里都是未经改动的官方 CLI，跑在真正的终端里；侧栏显示每个会话正在做什么。

    
在智能体改动的原位置直接阅读。选中几行、写条评论，这批评论会合成一条 prompt 交回给那个会话，由你自己发出。

    
仓库里的 Pull Request，直接用 GitHub 自带的搜索限定符筛选。把 PR 检出到 worktree，直接在 lich 里审查，再用基础分支允许的方式合并。

    
一个会话把任务交给另一个会话。通过 lich send 或 lich 的 MCP 工具发出，答复会回到发起请求的那个会话。

    
智能体操作一个你看得见的浏览器。它打开浏览器时，会话会多出一个标签页，终端与页面并排；lich 自己的光标标出它发出的每次点击、滚动和按键，你随时可以接管页面。

围绕智能体打造，而不是围绕编辑器

      
编辑器是为一个人敲代码设计的，智能体套壳工具则止步于一个终端。lich 是你正在用的那些智能体外面的一扇窗口：worktree、审查、Pull Request，以及能彼此协作的会话。

    

    

      
功能lichIDE 和套壳工具

      
        
未经改动的官方智能体 CLI，跑在真正的终端里多为自家智能体

        
多个智能体并行，各自用独立的 git worktree部分支持

        
Linux、Windows 和 macOS多半优先 macOS

        
免费开源，AGPL-3.0少见

        
用你自己的登录和套餐：无需账号、无需 API 密钥、没有遥测要用它们的账号

        
GPU 渲染的终端，滚动历史可搜索—

        
diff 评论合成一条 prompt 交回会话有限

        
在应用内审查并合并 Pull Request要去浏览器

        
会话之间通过 MCP 互派任务—

        
每个会话一个操作系统沙箱少见
