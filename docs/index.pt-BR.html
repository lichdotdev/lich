Ambiente de Desenvolvimento Agêntico

O lich é uma janela de desktop para os agentes de código que você já usa. Rode Claude Code, Codex, opencode e mais cinco lado a lado, cada um na própria branch do git. Converse com eles num chat ou no próprio terminal deles, corrija o que escreveram num editor que entende a sua linguagem e revise e faça o merge do pull request sem sair dali.

Grátis e open source · Linux, macOS e Windows · todas as formas de instalar

Recursos

  • Chat ou terminal

    Converse com um agente num chat, com as chamadas de ferramenta recolhidas e as edições em linhas que você abre, ou troque a mesma sessão para o terminal do próprio agente.

  • Uma branch por tarefa

    Cada sessão trabalha na própria worktree do git, então os agentes rodam em paralelo sem mexer nos arquivos uns dos outros.

  • Um editor que conhece o seu código

    Erros, autocompletar, documentação e ir para a definição vindos do language server no seu PATH, e teclas do Vim rodadas pelo seu próprio Neovim.

  • Revisão no lugar

    Leia o diff, comente as linhas e mande os comentários de volta ao agente num prompt só.

  • Pull requests

    Acompanhe, revise e faça o merge de pull requests do GitHub e merge requests do GitLab em Pulls.

  • Um navegador para o agente

    Uma página ao lado da sessão que o agente pilota e onde você desenha e deixa notas para ele ler.

  • Sessões que trabalham juntas

    Os agentes passam tarefas uns para os outros, fazem fork de si mesmos e reportam de volta pelas ferramentas do lich. Um subagente ganha card próprio.

  • Saiba qual precisa de você

    O anel da sessão fica âmbar quando o agente está esperando você, e uma notificação no desktop diz qual é.

  • Layouts

    Coloque sessões lado a lado; a grade acompanha quantas são e o espaço que a janela tem.

  • Serviços

    Salve uma vez um servidor de dev, um container ou um túnel; o lich sobe junto com o projeto e mantém rodando.

  • Seu plano à vista

    Contexto, cache de prompt, custo e quanto resta do seu plano, com perfis para cada conta em que você entra.

  • Ache qualquer sessão

    Ctrl+P encontra uma sessão pelo nome ou por algo que foi dito nela, e retoma conversas que você começou fora do lich.

  • Uma sandbox por sessão

    Opcional: uma home nova, o resto da máquina só para leitura e escrita só no próprio checkout.

  • Temas

    Experimente um tema do catálogo na janela inteira antes de ficar com ele, ou escreva o seu.

  • Extensões

    Adicione a tela que falta no lich, pelo catálogo ou com o SDK em Go.

  • …e mais

    Todas as versões estão no changelog.

Agentes

O lich roda as CLIs dos agentes do jeito que elas são distribuídas. Ele as acha no seu PATH ou instala pela tela de boas-vindas, e login, plano e configuração continuam com cada agente: o lich não tem conta nem chave de API própria.

Qualquer outra CLI roda numa sessão de terminal, com as mesmas worktrees, a mesma revisão e os mesmos pull requests. O que cada agente suporta está na tabela de provedores.

Baixar

Instale, abra um projeto e escolha um agente. O lich precisa do git no seu PATH, e do gh ou do glab para pull requests.

curl -fsSL https://raw.githubusercontent.com/lichdotdev/lich/main/install.sh | sh

Baixa o .deb, o .rpm ou o .pkg.tar.zst certo para a sua distro e confere com o checksums.txt. No Arch: yay -S lich-bin. Requer x86_64, glibc 2.34+ e zenity.

Debian, Ubuntu.debFedora, openSUSE.rpmArch.pkg.tar.zst
brew install --cask lichdotdev/tap/lich

Via Homebrew; o brew upgrade traz as próximas versões.

scoop install https://github.com/lichdotdev/lich/releases/latest/download/lich.json

Sobre

O lich é software livre sob a AGPL-3.0. Não envia telemetria e não tem conta para criar. É feito primeiro no Linux e roda também no macOS e no Windows.

Se o lich economiza o seu tempo, considere patrocinar o desenvolvimento.

  • Reporte um bug ou peça um recurso no issue tracker.
  • O que o lich deixa de fora de propósito, e por quê, está em Limites conhecidos.
  • Controle o lich por scripts com a linha de comando.
  • Achou uma falha de segurança? Leia antes a política de segurança.
