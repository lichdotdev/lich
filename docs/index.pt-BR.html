Uma tarefa, uma worktree, uma sessão. Digite o número de uma issue: o lich dá à branch o nome do título dela, cria a worktree a partir da sua base e entrega a issue ao agente como primeiro prompt.

    
Claude Code, Codex e opencode na mesma tela. Cada painel roda a CLI original, sem modificação, num terminal de verdade. A barra lateral mostra o que cada uma está fazendo.

    
Leia o que o agente mudou, direto no diff. Selecione as linhas e comente. Os comentários voltam juntos para a sessão num prompt só, que você envia quando quiser.

    
Os pull requests do repo, com os mesmos filtros de busca do GitHub. Faça checkout de um PR numa worktree, revise inline e faça o merge com os métodos que a branch base aceita.

    
Uma sessão passa tarefa para outra. O pedido vai pelo lich send ou pelas ferramentas MCP do lich, e a resposta volta para a sessão que pediu.

    
O agente usa um navegador que você vê. Quando ele abre um, a sessão ganha uma aba com o terminal ao lado da página; o cursor do lich mostra cada clique, rolagem e tecla que ele envia, e você assume a página quando quiser.

Feito em volta dos agentes, não de um editor

      
Editores foram feitos para uma pessoa digitando, e os wrappers de agente param num terminal só. O lich é a janela em volta dos agentes que você já usa: worktrees, revisão, pull requests e sessões que trabalham juntas.

Instale com um comando

      
Depois é só abrir um projeto e escolher o agente. Precisa do git no PATH; o gh só é usado para pull requests.

    

    

      
      
      
      

      

        
curl -fsSL https://raw.githubusercontent.com/lichdotdev/lich/main/install.sh | sh

        
Baixa o .deb, o .rpm ou o .pkg.tar.zst certo para a sua distro e confere com o checksums.txt. No Arch: yay -S lich-bin. Requer x86_64, glibc 2.34+ e zenity.

        
Debian, Ubuntu.debFedora, openSUSE.rpmArch.pkg.tar.zstQualquer distro.tar.zst

      

      

        
brew install --cask lichdotdev/tap/lich

        
Via Homebrew; o brew upgrade traz as próximas versões.

        
Apple Silicon.zipIntel.zip

      

      

        
scoop install https://github.com/lichdotdev/lich/releases/latest/download/lich.json

        
Via Scoop, ou pelo instalador, que se atualiza sozinho.

        
Instalador.exePortátil.zip
