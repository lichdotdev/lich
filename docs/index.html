Agentic Development Environment

lich is a desktop window for the coding agents you already use. Run Claude Code, Codex, opencode and five more side by side, each on its own git branch. Talk to them in a chat or in their own terminal, fix what they wrote in an editor that knows your language, and review and merge the pull request without leaving.

Download Source on GitHub

Free and open source · Linux, macOS and Windows · every way to install

Features

  • Chat or terminal

    Talk to an agent in a chat, with its tool calls folded and its edits as lines you open, or switch the same session to the agent's own terminal.

  • A branch per task

    Each session works in its own git worktree, so agents run in parallel without touching each other's files.

  • An editor that knows your code

    Errors, completions, docs and go to definition from the language server on your PATH, and Vim keys run by your own Neovim.

  • Review in place

    Read the diff, comment on its lines and send the comments back to the agent as one prompt.

  • Pull requests

    Check, review and merge GitHub pull requests and GitLab merge requests in Pulls.

  • A browser for the agent

    A page beside the session that the agent drives, and that you draw and leave notes on for it to read.

  • Sessions that work together

    Agents hand each other tasks, fork themselves and report back through lich's tools. A subagent gets a card of its own.

  • Know who needs you

    A session's ring turns amber when its agent waits on you, and a desktop notification says which one.

  • Layouts

    Put sessions side by side; the grid follows how many there are and the room the window has.

  • Services

    Save a dev server, a container or a tunnel once; lich starts it with the project and keeps it running.

  • Your plan in sight

    Context, prompt cache, cost and what is left of your plan, with profiles for each account you sign in with.

  • Find any session

    Ctrl+P finds a session by name or by something said in it, and resumes conversations you started outside lich.

  • A sandbox per session

    Optional: a fresh home, the rest of the machine read-only and only its checkout writable.

  • Themes

    Try a theme from the catalog on the whole window before you keep it, or write your own.

  • Extensions

    Add the screen lich is missing, from the catalog or with the Go SDK.

  • …and more

    Every release is in the changelog.

Agents

lich runs the agent CLIs as they ship. It finds them on your PATH or installs them from its Welcome screen, and your login, your plan and your config stay theirs: lich has no account and no API key of its own.

Any other CLI runs in a terminal session, with the same worktrees, review and pull requests. What each agent supports is in the provider table.

Download

Install it, open a project and pick an agent. lich needs git on your PATH, and gh or glab for pull requests.

curl -fsSL https://raw.githubusercontent.com/lichdotdev/lich/main/install.sh | sh

Picks the .deb, .rpm or .pkg.tar.zst for your distribution and checks it against checksums.txt. On Arch: yay -S lich-bin. x86_64, glibc 2.34+ and zenity.

Debian, Ubuntu.debFedora, openSUSE.rpmArch.pkg.tar.zst
brew install --cask lichdotdev/tap/lich

Through Homebrew; brew upgrade takes the next release.

Apple Silicon.zipIntel.zip
scoop install https://github.com/lichdotdev/lich/releases/latest/download/lich.json

Through Scoop, or the installer, which updates itself in place.

Installer.exePortable.zip

The checksum steps and every other way to install are in INSTALL.md.

About

lich is free software under the AGPL-3.0. It sends no telemetry and has no account to sign up for. It is built on Linux first, and runs on macOS and Windows too.

If lich saves you time, consider sponsoring its development.

  • Report a bug or ask for a feature on the issue tracker.
  • What lich leaves out on purpose, and why, is in Known limits.
  • Drive it from scripts with the command line.
  • Found a security issue? Read the security policy first.
