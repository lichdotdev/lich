에이전틱 개발 환경

lich는 이미 쓰고 있는 코딩 에이전트를 위한 데스크톱 창입니다. Claude Code, Codex, opencode 외 다섯 가지 에이전트를 각자 자기 git 브랜치에서 나란히 실행하세요. 채팅이나 에이전트 자체 터미널로 대화하고, 에이전트가 쓴 코드는 언어를 이해하는 에디터에서 고치고, 풀 리퀘스트 리뷰와 병합까지 창을 떠나지 않고 끝낼 수 있습니다.

기능

  • 채팅 또는 터미널

    도구 호출은 접히고 수정 내용은 열어 볼 수 있는 줄로 표시되는 채팅으로 에이전트와 대화하거나, 같은 세션을 에이전트 자체 터미널로 전환하세요.

  • 작업마다 브랜치 하나

    세션마다 자기 git worktree에서 작업하므로, 에이전트들이 서로의 파일을 건드리지 않고 동시에 실행됩니다.

  • 코드를 이해하는 에디터

    PATH에 있는 언어 서버가 오류, 자동 완성, 문서, 정의로 이동을 제공하고, Vim 키는 내 Neovim이 처리합니다.

  • 그 자리에서 리뷰

    diff를 읽고 줄마다 코멘트를 남긴 뒤, 모은 코멘트를 프롬프트 하나로 에이전트에게 돌려보내세요.

  • 풀 리퀘스트

    GitHub 풀 리퀘스트와 GitLab 머지 리퀘스트를 풀 리퀘스트 화면에서 확인하고, 리뷰하고, 병합하세요.

  • 에이전트를 위한 브라우저

    세션 옆에 에이전트가 조작하는 페이지가 열리고, 나는 그 위에 그림을 그리거나 메모를 남겨 에이전트가 읽게 할 수 있습니다.

  • 함께 일하는 세션

    에이전트는 lich의 도구로 서로 작업을 넘기고, 자신을 포크하고, 결과를 보고합니다. 서브에이전트도 자기 카드를 받습니다.

  • 나를 기다리는 세션을 한눈에

    에이전트가 내 응답을 기다리면 세션의 링이 주황색으로 바뀌고, 데스크톱 알림이 어느 세션인지 알려 줍니다.

  • 레이아웃

    세션을 나란히 놓으면 세션 수와 창의 공간에 맞춰 그리드가 바뀝니다.

  • 서비스

    개발 서버, 컨테이너, 터널을 한 번 저장해 두면 lich가 프로젝트와 함께 시작하고 계속 실행해 둡니다.

  • 한눈에 보는 플랜

    컨텍스트, 프롬프트 캐시, 비용, 플랜의 남은 사용량을 보여 주고, 로그인하는 계정마다 프로필을 둘 수 있습니다.

  • 어떤 세션이든 찾기

    Ctrl+P로 세션 이름이나 대화 내용으로 세션을 찾고, lich 밖에서 시작한 대화도 이어서 할 수 있습니다.

  • 세션별 샌드박스

    선택 사항입니다. 새 홈 디렉터리가 주어지고, 머신의 나머지는 읽기 전용이며, 쓰기는 해당 체크아웃에만 허용됩니다.

  • 테마

    카탈로그의 테마를 창 전체에 미리 적용해 보고 고르거나, 직접 만들어 보세요.

  • 확장 프로그램

    lich에 없는 화면을 카탈로그에서 추가하거나 Go SDK로 직접 만드세요.

  • …그리고 더 많은 기능

    모든 릴리스는 변경 내역에 있습니다.

에이전트

lich는 에이전트 CLI를 배포된 그대로 실행합니다. PATH에서 찾거나 시작하기 화면에서 설치하며, 로그인, 플랜, 설정은 각 에이전트의 것을 그대로 씁니다. lich에는 자체 계정도 API 키도 없습니다.

  • Claude Codeclaude
  • Codexcodex
  • Antigravityagy
  • opencodeopencode
  • oh-my-piomp
  • Crushcrush
  • Cursor CLIcursor-agent
  • Kiro CLIkiro-cli

그 밖의 CLI는 터미널 세션에서 실행되며, 같은 worktree와 리뷰, 풀 리퀘스트를 그대로 씁니다. 에이전트별 지원 범위는 프로바이더 표에서 확인하세요.

다운로드

설치한 다음 프로젝트를 열고 에이전트를 고르면 됩니다. PATH에 git이 있어야 하고, 풀 리퀘스트에는 gh나 glab이 필요합니다.

curl -fsSL https://raw.githubusercontent.com/lichdotdev/lich/main/install.sh | sh

배포판에 맞는 .deb, .rpm, .pkg.tar.zst 패키지를 골라 checksums.txt로 검증합니다. Arch에서는 yay -S lich-bin. x86_64, glibc 2.34 이상과 zenity가 필요합니다.

Debian, Ubuntu.debFedora, openSUSE.rpmArch.pkg.tar.zst
brew install --cask lichdotdev/tap/lich

Homebrew로 설치하며, 다음 릴리스는 brew upgrade로 받습니다.

Apple Silicon.zipIntel.zip
scoop install https://github.com/lichdotdev/lich/releases/latest/download/lich.json

Scoop으로 설치하거나 설치 프로그램을 쓰세요. 설치 프로그램은 스스로 업데이트됩니다.

설치 프로그램.exe포터블.zip

체크섬 확인 절차와 그 밖의 모든 설치 방법은 INSTALL.md에 있습니다.

소개

lich는 AGPL-3.0 라이선스의 자유 소프트웨어입니다. 텔레메트리를 보내지 않고, 가입할 계정도 없습니다. Linux를 우선으로 만들지만 macOS와 Windows에서도 실행됩니다.

lich로 시간을 아꼈다면 개발을 후원해 주세요.

  • 버그 제보와 기능 요청은 이슈 트래커에 남겨 주세요.
  • lich가 일부러 빼 둔 것과 그 이유는 알려진 한계에 있습니다.
  • 명령줄로 스크립트에서 lich를 다룰 수 있습니다.
  • 보안 문제를 발견했다면 먼저 보안 정책을 읽어 주세요.
