## [0.75.0] - 2026-10-21

### Added

- 리뷰 탭의 Markdown 파일에는 "파일을 컨텍스트로 추가" 옆에 미리보기 버튼이 있어, diff 대신 표와 링크를 포함해 렌더링된 파일을 보여 줍니다. 다시 누르면 diff로 돌아갑니다. 풀 리퀘스트 화면에서는 해당 풀 리퀘스트가 추가한 파일에만 이 버튼이 있습니다.
- 코드 탭에서 열어 둔 파일에서 Ctrl+F(macOS는 Cmd+F)를 누르면 파일 안의 텍스트를 찾을 수 있습니다. 파일 이름 아래에 나타나는 바가 일치하는 부분을 모두 강조하고, Enter와 Shift+Enter로 차례로 이동하며, 대/소문자, 단어 단위, 정규식 일치를 지원합니다. 바의 목록 버튼은 일치하는 줄을 모두 바 아래에 보여 주고, 하나를 누르면 코드의 해당 위치로 이동합니다. Escape로 닫습니다.
- 세션 카드의 툴팁에 세션이 실행 중인 모델이 표시됩니다. Claude Code, Codex, Kiro CLI에서 지원합니다. 예를 들어 `/model` 이후처럼 세션을 연 모델과 달라지면 "…(으)로 시작, … 실행 중"으로 표시됩니다.
- 풀 리퀘스트 화면에서 풀 리퀘스트의 제목과 설명을 편집해 GitHub로 보낼 수 있습니다. 제목 뒤의 연필 아이콘으로 그 자리에서 이름을 바꾸며, Enter를 누르거나 다른 곳을 누르면 저장되고 Escape를 누르면 취소됩니다. 개요의 설명 옆 편집을 누르면 Markdown으로 열리고, 저장 또는 Ctrl+Enter(macOS는 Cmd+Enter)로 저장합니다. 긴 설명은 스크롤바와 함께 필드 안에서 스크롤되어 저장 버튼이 화면에 남아 있습니다. 각각 바뀐 부분만 보내므로, 설명을 저장해도 그사이 GitHub에서 한 이름 변경이 되돌려지지 않습니다.
- 프로필에 고유한 색상과 이미지를 지정할 수 있습니다. 설정 › 프로바이더에서 프로필의 ⋯ 메뉴에 세션 카드와 같은 8가지 색상을 고르는 색상과, 최대 10 MB의 PNG, JPEG, GIF, WebP를 받아 가운데 정사각형을 사용하는 이미지 선택…이 생겼습니다. 이미지나 색상은 프로필이 표시되는 모든 곳에 나타납니다. 프로필 목록과 선택기, 사이드바 하단, 다음에서 계속입니다. 이미지 제거를 누르면 프로필 색상 위의 이니셜로 돌아갑니다.

### Changed

- 사이드바의 카드 묶음(worktree, 폴더, 고정 묶음)이 이제 첫 카드가 열릴 때 서서히 커지고 마지막 카드가 닫힐 때 서서히 줄어듭니다. 이전에는 한꺼번에 나타나고 사라졌습니다. 목록이 묶음으로 나뉠 때 표시되는 헤더도 같은 방식으로 펼쳐지고, 하나만 남으면 접힙니다.
- 체크가 아직 실행 중인 풀 리퀘스트는 체크 탭과 탭 위의 상태 줄에서 멈춰 있던 시계 대신 스피너가 돕니다.
- 버튼을 누르는 동안 1픽셀 가라앉지 않으므로 창의 모든 버튼이 같게 동작합니다. 이 움직임이 있던 버튼을 없던 버튼에 맞췄습니다.

### Removed

- **호환성 변경:** `lich open --worktree`나 에이전트의 `open_session`이 새 worktree에서 세션을 시작할 때 lich가 더 이상 `.lich/setup-worktree.sh`를 실행하지 않습니다. 저장소에 있는 파일은 그대로 둡니다. worktree가 의존성 설치에 이 파일을 사용했다면 새 worktree의 터미널에서 직접 실행하거나(`sh .lich/setup-worktree.sh`) 에이전트에게 요청하세요. gitignore 대상인 `.env*` 파일(또는 `.worktreeinclude`가 지정한 파일)의 복사와 `LICH_WORKTREE_PORT` 개발 서버 포트는 그대로입니다.

### Fixed

- lich가 같은 순간에 해당 체크아웃의 상태나 diff를 읽고 있다는 이유로 에이전트의 `git commit`, `rebase`, `stash`가 가끔 "Unable to create '.git/index.lock': File exists"로 실패하던 문제를 고쳤습니다. lich의 읽기는 인덱스를 건드리지 않습니다.
- 닫은 세션의 카드가 한꺼번에 사라지지 않고 다시 사이드바에서 서서히 줄어들며 사라집니다.
- 세션에서 Ctrl+Z를 눌러도 에이전트가 영영 멈추지 않습니다. 이전에는 에이전트가 일시 중단되었고 lich에서는 되살릴 방법이 없었습니다. 이제 lich가 이 키를 세션에 전달하지 않습니다.
- 하단 바의 플랜 사용량 툴팁에 있는 막대가, Everforest처럼 팝오버와 음소거 색상이 같은 테마에서도 빈 트랙을 다시 표시합니다. 이전에는 채워진 부분만 그려졌습니다.
- 풀 리퀘스트 화면에서 풀 리퀘스트 목록을 열거나 닫아도 활성 프로젝트 탭이 아래 패널에서 떨어졌다가 다시 붙지 않습니다. 탭은 내내 붙어 있다가 목록이 그 아래로 밀려 들어오면 목록 위로 옮겨 갑니다.
