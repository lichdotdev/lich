## [0.76.0] - 2026-10-21

### Added

- 코드 탭에서 열어 둔 Markdown 파일에는 리뷰 탭과 같은 미리보기 버튼이 "읽기 전용" 표시 옆에 있어, 소스 대신 표와 링크를 포함해 렌더링된 파일을 보여 줍니다. 다시 누르면 소스로 돌아갑니다. 다른 파일은 소스로 열립니다.

### Changed

- 리뷰 탭, 코드 탭, 풀 리퀘스트 화면에서 리뷰 코멘트 묶음에 "보내기"를 누르면 코멘트가 세션에 프롬프트로 전송됩니다. 이전에는 프롬프트에 놓인 채 Enter를 기다렸습니다. 셸 세션은 코멘트를 그대로 둡니다. 그곳에서는 Enter가 코멘트를 명령으로 실행하기 때문입니다.

### Fixed

- 세션 터미널에서 데드 키가 조합됩니다. macOS에서 ~ 다음에 a를 누르면 ã, ' 다음에 c를 누르면 ç가 입력됩니다. 이전에는 악센트 기호가 글자보다 먼저 혼자 도착했습니다. 일본어나 중국어 IME처럼 입력기가 아직 조합 중인 텍스트도 확정되기 전에는 프로그램에 전달되지 않습니다.
- Claude Code 세션에서 `/model`로 모델을 바꾼 뒤, 푸터와 세션 카드의 툴팁에는 첫 턴이 끝나는 즉시 새 모델이 표시됩니다. 이전에는 Claude Code가 그 턴의 마지막 줄을 쓰기 전에 lich가 트랜스크립트를 읽어서, 이후 턴이나 재연결 때까지 이전 모델이 남아 있었습니다.
- macOS에서 닫기, 최소화, 확대/축소 버튼이 제목 표시줄 가운데에 유지됩니다. 이전에는 창이 열릴 때, 다른 앱으로 전환했다가 돌아올 때, 시스템이 라이트와 다크 사이를 전환할 때 macOS가 버튼을 표시줄 위쪽으로 되돌렸고, 창 크기를 조절할 때까지 그대로였습니다.
