## [0.75.0] - 2026-10-21

### Added

- 리뷰 탭의 Markdown 파일에는 "파일을 컨텍스트로 추가" 옆에 미리보기 버튼이 있어, diff 대신 표와 링크를 포함해 렌더링된 파일을 보여 줍니다. 다시 누르면 diff로 돌아갑니다. 풀 리퀘스트 화면에서는 해당 풀 리퀘스트가 추가한 파일에만 이 버튼이 있습니다.
- 코드 탭에서 열어 둔 파일에서 Ctrl+F(macOS는 Cmd+F)를 누르면 파일 안의 텍스트를 찾을 수 있습니다. 파일 이름 아래에 나타나는 바가 일치하는 부분을 모두 강조하고, Enter와 Shift+Enter로 차례로 이동하며, 대/소문자, 단어 단위, 정규식 일치를 지원합니다. 바의 목록 버튼은 일치하는 줄을 모두 바 아래에 보여 주고, 하나를 누르면 코드의 해당 위치로 이동합니다. Escape로 닫습니다.
- 세션 카드의 툴팁에 세션이 실행 중인 모델이 표시됩니다. Claude Code, Codex, Kiro CLI에서 지원합니다. 예를 들어 `/model` 이후처럼 세션을 연 모델과 달라지면 "…(으)로 시작, … 실행 중"으로 표시됩니다.
- 풀 리퀘스트 화면에서 풀 리퀘스트의 제목과 설명을 편집해 GitHub로 보낼 수 있습니다. 제목 뒤의 연필 아이콘으로 그 자리에서 이름을 바꾸며, Enter를 누르거나 다른 곳을 누르면 저장되고 Escape를 누르면 취소됩니다. 개요의 설명 옆 편집을 누르면 Markdown으로 열리고, 저장 또는 Ctrl+Enter(macOS는 Cmd+Enter)로 저장합니다. 긴 설명은 스크롤바와 함께 필드 안에서 스크롤되어 저장 버튼이 화면에 남아 있습니다. 각각 바뀐 부분만 보내므로, 설명을 저장해도 그사이 GitHub에서 한 이름 변경이 되돌려지지 않습니다.
- 프로필에 고유한 색상과 이미지를 지정할 수 있습니다. 설정 › 프로바이더에서 프로필의 ⋯ 메뉴에 세션 카드와 같은 8가지 색상을 고르는 색상과, 최대 10 MB의 PNG, JPEG, GIF, WebP를 받아 가운데 정사각형을 사용하는 이미지 선택…이 생겼습니다. 이미지나 색상은 프로필이 표시되는 모든 곳에 나타납니다. 프로필 목록과 선택기, 사이드바 하단, 다음에서 계속입니다. 이미지 제거를 누르면 프로필 색상 위의 이니셜로 돌아갑니다.

### Changed

- 사이드바의 카드 묶음(worktree, 폴더, 고정 묶음)이 이제 첫 카드가 열릴 때 서서히 커지고 마지막 카드가 닫힐 때 서서히 줄어듭니다. 이전에는 한꺼번에 나타나고 사라졌습니다. 목록이 묶음으로 나뉠 때 표시되는 헤더도 같은 방식으로 펼쳐지고, 하나만 남으면 접힙니다.
- 체크가 아직 실행 중인 풀 리퀘스트는 체크 탭과 탭 위의 상태 줄에서 멈춰 있던 시계 대신 스피너가 돕니다.
- 버튼을 누르는 동안 1픽셀 가라앉지 않으므로 창의 모든 버튼이 같게 동작합니다. 이 움직임이 있던 버튼을 없던 버튼에 맞췄습니다.

### Removed

- **호환성 변경:** `lich open --worktree`나 에이전트의 `open_session`이 새 worktree에서 세션을 시작할 때 lich가 더 이상 `.lich/setup-worktree.sh`를 실행하지 않습니다. 저장소에 있는 파일은 그대로 둡니다. worktree가 의존성 설치에 이 파일을 사용했다면 새 worktree의 터미널에서 직접 실행하거나(`sh .lich/setup-worktree.sh`) 에이전트에게 요청하세요. gitignore 대상인 `.env*` 파일(또는 `.worktreeinclude`가 지정한 파일)의 복사와 `LICH_WORKTREE_PORT` 개발 서버 포트는 그대로입니다.

### Fixed

- lich가 같은 순간에 해당 체크아웃의 상태나 diff를 읽고 있다는 이유로 에이전트의 `git commit`, `rebase`, `stash`가 가끔 "Unable to create '.git/index.lock': File exists"로 실패하던 문제를 고쳤습니다. lich의 읽기는 인덱스를 건드리지 않습니다.
- 닫은 세션의 카드가 한꺼번에 사라지지 않고 다시 사이드바에서 서서히 줄어들며 사라집니다.
- 세션에서 Ctrl+Z를 눌러도 에이전트가 영영 멈추지 않습니다. 이전에는 에이전트가 일시 중단되었고 lich에서는 되살릴 방법이 없었습니다. 이제 lich가 이 키를 세션에 전달하지 않습니다.
- 하단 바의 플랜 사용량 툴팁에 있는 막대가, Everforest처럼 팝오버와 음소거 색상이 같은 테마에서도 빈 트랙을 다시 표시합니다. 이전에는 채워진 부분만 그려졌습니다.
- 풀 리퀘스트 화면에서 풀 리퀘스트 목록을 열거나 닫아도 활성 프로젝트 탭이 아래 패널에서 떨어졌다가 다시 붙지 않습니다. 탭은 내내 붙어 있다가 목록이 그 아래로 밀려 들어오면 목록 위로 옮겨 갑니다.

## [0.74.0] - 2026-10-20

- F11을 누르면 창이 전체 화면으로 전환되고 다시 누르면 돌아오며, 전체 화면인 동안에는 최소화, 최대화, 닫기 버튼이 표시되지 않습니다. 이 단축키는 설정 › 단축키에서 바꿀 수 있습니다.

### Changed

- 베이스와 충돌하는 풀 리퀘스트는 더 이상 제목 아래에 충돌하는 파일을 나열하지 않습니다. 충돌 파일 수는 "…와(과) 충돌" 상태에 표시되며, 이를 누르면 화면 위에 패널이 열려 각 파일의 이름을 보여 줍니다.
- 풀 리퀘스트의 **충돌 해결**과 **CI 오류 고치기**, 그리고 `#123` 이슈에서 시작한 worktree는 이제 메시지를 자신이 여는 세션으로 보냅니다. 이전에는 메시지가 프롬프트에 입력된 채 Enter를 누르기를 기다렸습니다. 해당 체크아웃의 터미널 카드에는 아무것도 전송되지 않습니다.

### Fixed

- 코드 또는 리뷰 도크를 열거나 크기를 조절해 활성 프로젝트 탭이 도크 영역을 침범하면, 이제 탭이 터미널 아일랜드에서 분리되고 공간이 다시 충분해지면 연결됩니다.
- macOS에서 닫기, 최소화, 확대 버튼이 네이티브 창 제목 표시줄의 위쪽 가장자리에 붙지 않고 가운데에 놓이며, 인터페이스 확대/축소를 따릅니다.
- 상단 바를 끌어 창을 움직일 수 있습니다. 마지막 탭 뒤쪽과 브랜드 및 버튼 주변의 빈 곳에서도 됩니다. 이전에는 상단 바의 어느 부분으로도 창을 움직일 수 없었습니다.
- 풀 리퀘스트 화면이 새로 고침을 누르지 않아도 표시 내용을 최신으로 유지합니다. GitHub가 병합 가능 여부를 계산하는 중에는 몇 초마다, 화면이 열려 있는 동안에는 1분마다, 그리고 창으로 돌아올 때 풀 리퀘스트를 다시 읽으므로, lich 밖에서 한 푸시, 병합, 충돌도 저절로 나타납니다.

## [0.73.0] - 2026-10-20

> [!IMPORTANT]
> **모든 사용자: 이제 네이티브 창이 lich의 유일한 창입니다.** lich는 실행할 때마다 네이티브 창을 열며, 웹 창과 내장 Chromium은 없어졌습니다.

### Added

- **Windows와 macOS의 네이티브 창에서 클릭할 수 있는 데스크톱 알림.** Linux와 마찬가지로, 입력이 필요하거나 턴을 마친 세션이 열기와 닫기 버튼이 있는 알림을 띄웁니다. 열기를 누르면 lich가 해당 세션의 카드로 이동하고, 응답하거나 세션을 열면 알림이 사라집니다. macOS에서는 Lich.app으로 lich를 실행해야 하며 권한을 한 번 요청합니다. Windows에서는 사용자를 기다리는 세션의 알림이 조작할 때까지 화면에 남습니다.
- 사용자 지정 바이너리로 세션을 시작하면 설정 › 프로바이더의 프로필 아래에 경고가 표시되며, 바이너리 경로와 그 위치를 보여 주는 버튼, 기본값으로 되돌리는 버튼이 함께 나옵니다. 자체 로그인 또는 설정 디렉터리를 지정하는 래퍼는 프로필보다 우선하며, 바이너리 설정은 화면 맨 아래에 접혀 있습니다.

### Changed

- 세션의 프로세스가 종료되면 터미널 하단의 띠 대신 오른쪽 아래의 토스트가 어떻게 할지 묻습니다. 대화가 있는 카드는 같은 대화를 다시 여는 재개(처음 시작한 프로필에서), 재시작처럼 카드에서 새 대화를 시작하는 새로 시작, 세션 닫기를 제공합니다. 셸이나 첫 프롬프트 전에 끝난 에이전트는 다시 시작과 세션 닫기를 제공합니다. 토스트를 닫으면 카드는 그대로 남고, 카드에 포커스하면 토스트가 다시 나타납니다.
- **프로젝트의 프로필이 모든 카드가 아니라 사이드바 맨 아래에 표시됩니다.** 한 프로바이더에 로그인이 둘 이상이면, 사이드바의 마지막 줄에 이 프로젝트의 새 세션이 시작되는 프로필이 표시됩니다. 화면에 보이는 카드의 프로바이더, 터미널이면 기본 프로바이더 기준입니다. 눌러서 다른 로그인을 고르거나(각 로그인의 5시간 사용량이 함께 표시됩니다) 전역의 로그인으로 되돌릴 수 있고, 다른 프로바이더는 같은 메뉴에서 바꿉니다. 카드에는 더 이상 브랜치 옆에 프로필 칩이 붙지 않습니다.

### Removed

- 웹 창. lich는 네이티브 창을 열며, 릴리스에 더 이상 Chromium이 포함되지 않습니다. 설정의 창 선택(웹 또는 네이티브)과 다른 창을 여는 트레이 항목이 없어졌고, `lich -- <chromium flags>`, `lich --shell`, `LICH_SHELL`도 없어졌습니다. 네이티브 창을 시작할 수 없으면 lich가 이유와 로그 위치를 알려 줍니다.

### Fixed

- Claude Code 또는 Codex 프로필로 로그인할 때, 브라우저에서 마치거나 붙여 넣은 코드를 제출하면 인증 중이라고 표시됩니다. 이전에는 대화 상자가 끝까지 로그인을 기다리기만 했고 코드 입력란은 그냥 비워졌습니다.
- 브라질 포르투갈어에서 모든 메시지가 worktree를 "a worktree"로 부릅니다. 일부 메시지는 "o worktree"라고 했습니다.
- macOS에서 네이티브 창의 닫기, 최소화, 확대 버튼이 다시 나타납니다. 0.72.0부터 상단 바에 그 자리가 비어 있었습니다.
- Windows에서 네이티브 창으로 lich를 업데이트할 때 "Setup was unable to automatically close all applications"와 함께 롤백되던 문제를 고쳤습니다. 설치 프로그램이 교체해야 하는 `lich-native.exe`에서 창이 열린 채 남아 있었습니다. 이제 설치 프로그램이 실행되기 전에 창이 닫히고, lich가 돌아오면 다시 열립니다. 0.72.0 이하에서 업데이트할 때는 한 번 더 발생합니다. 메시지가 나오면 작업 관리자에서 `lich-native.exe`를 종료하고 다시 시도를 선택한 뒤, 시작 메뉴에서 lich를 여세요.
- lich가 종료되었거나 다시 시작 중이어서 없는 동안 네이티브 창을 닫으면, "창을 닫을 때" 설정과 관계없이 창이 닫힙니다. 묻기나 종료로 설정하면 창이 열린 채 세션을 셀 수 없다는 오류만 표시되었습니다.
- 좁은 설정 창에서 컨트롤이 너무 넓어 한 줄에 함께 들어가지 않는 설정(예: 프로바이더의 프로필 선택기)은 이제 제목과 설명 아래에 컨트롤을 놓습니다. 이전에는 텍스트가 좁은 틈으로 찌그러져 글자 단위로 줄바꿈되었습니다. 프로바이더의 문서 링크도 켜짐 스위치와 겹치지 않고 이름 아래로 이동합니다.

- **Claude Code가 이미 답한 곳에서 "이 폴더를 신뢰하나요?"를 다시 묻지 않습니다.** 메인 계정에서
  신뢰한 폴더는 다른 모든 Claude Code 프로필에서도 그곳의 다음 세션부터 신뢰되고, 샌드박스 Claude
  Code 세션은 질문 없이 열립니다. lich가 대신 연 세션이 더 이상 Enter를 누르면 종료되는 그 화면에
  머물지 않습니다.
- **다시 연 네이티브 창이 각 세션이 어디로 갔는지 알아냅니다.** `cd`로, 또는 tmux나 ssh로 이동한
  세션이 다음 `cd`까지 체크아웃의 경로, 브랜치, 변경 사항을 표시한 채 돌아왔는데, 이제 창이 연결될
  때 각 세션이 마지막으로 있던 곳을 읽어 옵니다.
- **네이티브 창이 에이전트 프롬프트를 프롬프트 언어로 작성합니다.** 풀 리퀘스트와 이슈 인계, 그리고
  리뷰 코멘트 묶음이 항상 영어로 입력되었습니다.
- **재연결 중 테마를 바꿔도 네이티브 창이 더 이상 충돌하지 않습니다.** 창이 재시작된 lich에 다시
  연결되는 동안 테마를 바꾸거나 시스템이 밝은 테마와 어두운 테마를 전환하면, 재연결이 방금 해제한
  터미널을 그려 창이 종료될 수 있었습니다.
- **중국어, 일본어, 한국어 텍스트가 더 이상 Linux의 네이티브 창을 멈추지 않습니다.** CJK 텍스트로
  가득한 세션, 리뷰, 풀 리퀘스트가 창을 몇 초간 멈춰 "응답 없음"이 뜰 정도였고, 확대하면 멈춤이
  다시 나타났습니다.
- **네이티브 창이 메모리를 덜 사용합니다.** 각 세션의 터미널과 리뷰가 대체 글꼴을 각자 따로
  불러왔고, CJK나 이모지 글꼴은 하나에 수십 MB였습니다. 이제 세션 여섯 개를 열었을 때 메모리
  사용량이 이전의 약 절반입니다. CJK 글꼴이 설치된 컴퓨터에서는 시작도 더 빠릅니다.
- **대화가 이미 열려 있는 세션을 다시 열면 그 카드로 포커스가 이동합니다.** 기록의 닫힌 세션, 실행
  취소한 닫기, 기존 worktree가 다른 카드가 아직 실행 중인 대화의 두 번째 카드로 돌아와 둘이 같은
  대화 기록에 썼습니다. 이제 기록은 그런 대화를 마지막으로 닫은 시점 기준으로 한 번만 보여 주고,
  지우기는 그 대화의 모든 사본을 제거합니다.

## [0.69.0] - 2026-10-16

### Added

- **macOS에서 네이티브 창을 사용할 수 있습니다(실험).** Lich.app이 Apple Silicon과 Intel 모두에서
  lich와 함께 네이티브 창을 제공하며, 설정 › 모양 › 창에서 Linux, Windows와 같이 선택할 수
  있습니다. 터미널에서는 Option 키가 Terminal.app처럼 문자를 입력하므로, 에이전트의 Option+글자
  단축키는 터미널에 전달되지 않습니다. 지금까지는 GitHub의 macOS 머신에서만 실행해 보았습니다.
  알림은 클릭할 수 없는 일반 알림이며, 메뉴 막대 항목은 없습니다.
- **파일 트리가 훨씬 더 많은 파일 형식을 인식합니다.** Java, Gradle, C와 C++, C#, PHP, Ruby,
  Swift, SQL, Vue, Svelte, Terraform, Dockerfile, .gitignore를 비롯해 약 서른 가지가 더 이제
  파일 트리와 검색 결과에서 일반 파일 아이콘 대신 각자의 아이콘으로 표시됩니다.

### Fixed

- **`lich quit`이 네이티브 창을 닫습니다.** 백엔드가 사라진 뒤에도 창이 열린 채 lich를 연결이
  끊긴 것으로 표시했습니다. 이제 트레이의 종료와 중지 신호도 창을 닫으며, 업데이트 후 재시작할
  때는 창이 그대로 유지됩니다.
- **네이티브 창이 마지막 세션을 닫을 때 worktree 삭제를 제안합니다.** 닫힘 토스트에 실행 취소
  옆으로 worktree 삭제 버튼이 생겼으며, lich가 만들지 않은 worktree나 커밋하지 않은 변경 사항이
  있는 worktree는 삭제하기 전에 대화상자에서 알려 줍니다.

- **네이티브 창의 터미널이 포인터 아래의 셀을 선택합니다.** 클릭, 드래그 선택, 링크, 마우스를
  추적하는 프로그램이 모두 터미널 패딩만큼 어긋난 포인터 위치를 읽었기 때문에, 가리킨 셀이 아니라
  오른쪽 아래의 셀이 선택되었습니다. 배율이 적용된 디스플레이에서는 어긋남이 셀 하나에 가까웠습니다.
- **네이티브 창의 터미널이 이모지를 그립니다.** Noto Color Emoji 같은 컬러 이모지 글꼴은 각
  이모지를 윤곽선이 아니라 그림으로 저장하는데, 터미널은 윤곽선만 그릴 수 있어서 모든 이모지가
  빈 칸으로 보였습니다. 이제 컬러로, 두 셀 너비로 그려집니다.
- **네이티브 창의 파일 트리가 파일마다 언어 아이콘을 표시합니다.** 모든 파일이 똑같은 일반 파일
  아이콘으로 그려졌는데, 이제 웹 창이 붙여 주는 것과 같은 아이콘이 붙습니다.
- **에이전트가 연 풀 리퀘스트가 턴이 끝나면 카드에 표시됩니다.** 배지는 브랜치나 마지막 커밋이
  바뀔 때만 다시 확인했는데, 풀 리퀘스트를 열어도 둘 다 바뀌지 않아서 창이 포커스를 잃었다가
  되찾을 때까지 기다려야 했습니다.
- **Windows에서 네이티브 창이 열립니다.** 글꼴을 Windows에 없는 fontconfig로 찾으려다 시작할 때
  창이 닫혔고, lich는 웹 창으로 대체되었습니다. 이제 Windows에서는 설치된 글꼴을 직접 찾으며,
  터미널 기본 글꼴은 Cascadia Mono 또는 Consolas이고 설정의 글꼴 선택기에도 목록이 표시됩니다.
- **밝은 테마와 어두운 테마를 전환해도 네이티브 창이 더 이상 멈추지 않습니다.** Claude Code처럼
  터미널의 색 구성표를 따르는 세션이, 창이 아직 터미널을 붙잡고 있는 동안 변경 사실을 전달받아
  창이 멈춘 뒤 닫혔습니다.
