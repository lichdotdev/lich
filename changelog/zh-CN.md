## [0.71.0] - 2026-10-17

### Added

- **原生窗口中的分屏布局（实验性）。** 可以把任意已打开项目的会话并排放在一起，并按需要自由分割：Ctrl+Shift+G 把当前聚焦的会话向右分割，Ctrl+Shift+I 向下分割，两者都会询问放入哪个会话；也可以把侧边栏中的卡片拖到某个窗格的边缘。要调整布局，可以拖动窗格标题到另一个窗格的边缘，或拖到其中间以交换两者，并用 Ctrl+Shift+R 在并排和上下堆叠之间切换一对窗格。每个布局都是项目之后的一个标签页，显示其各窗格的状态，双击即可重命名；拖动两个窗格之间的间隙可调整大小，用 Ctrl+Shift+M 放大一个窗格，用 Ctrl+Shift+F 在窗格之间切换，用 Ctrl+Shift+W 移出一个窗格；只剩一个窗格的布局会关闭。把拖动中的会话停在另一个标签页上，该标签页就会弹出，就像浏览器拖动文件时那样。侧边栏和页脚会跟随当前聚焦的窗格。
- **把会话的委派并排显示。** 在原生窗口中，如果一个会话打开了其他会话（不论属于哪个项目），页脚会提供这些会话：并排显示 会把它与其委派一起排布，委派堆叠在它的右侧，能放多少放多少。在布局中，其窗格标题会显示有多少个委派在场，并可添加其余的；若要把某个委派从另一个布局中移出，会先询问。布局中的卡片会标明所在布局。
- **必需的检查会被标出。** 在原生窗口中，拉取请求的 检查 标签页会像 GitHub 一样，用 必需 标出那些控制其合并的检查。

### Changed

- **lich 迁到 `lichdotdev/lich`。** 仓库已迁至 [lichdotdev](https://github.com/lichdotdev) 组织，网站迁至 [lichdotdev.github.io/lich](https://lichdotdev.github.io/lich/)。旧的 GitHub 链接、克隆和更新检查都会重定向；旧网站的书签则不会。

### Fixed

- **“新功能”会跟随你切换的语言。** 在原生窗口中，更改界面语言后，发布说明仍停留在最初阅读时的语言，只有分组名称变成了新语言。
- **差异视图不再因中日韩文本而卡顿，也不再为每个文件堆积内存。** 在原生窗口中，包含中文、日文或韩文的 审查 或拉取请求的 文件，会因为每个新字符都要查找字体而可能卡住数秒；而且每个文件的差异都各自保留一份字体副本，因此大型拉取请求会占用数百兆内存。
