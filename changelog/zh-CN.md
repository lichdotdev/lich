## [0.75.0] - 2026-10-21

### Added

- 审查标签页中的 Markdown 文件，在“将文件添加为上下文”旁边有一个预览按钮，点击后以渲染后的样式（包括表格和链接）显示该文件，取代其差异视图。再次点击即可回到差异视图。在拉取请求屏幕上，只有该拉取请求新增的文件才有这个按钮。
- 在代码标签页中打开的文件里按 Ctrl+F（macOS 上为 Cmd+F）可以查找文本。文件名下方的搜索栏会高亮所有匹配项，用 Enter 和 Shift+Enter 在匹配项之间跳转，并支持区分大小写、全字匹配或正则表达式。其列表按钮会在搜索栏下方列出所有含匹配项的行，点击某一行即可跳转到对应代码。按 Escape 关闭搜索栏。
- 会话卡片的提示会显示该会话正在运行的模型，支持 Claude Code、Codex 和 Kiro CLI。当它不再是会话打开时所用的模型时，例如执行过 `/model` 之后，该行会显示为“以 … 打开，正在运行 …”。
- 拉取请求屏幕可以编辑拉取请求的标题和描述，并将其发送到 GitHub。标题后面的铅笔图标可以就地重命名：按 Enter 或点击其他位置保存，按 Escape 取消。概览中“描述”旁边的“编辑”会以 Markdown 形式打开描述，可通过“保存”或 Ctrl+Enter（macOS 上为 Cmd+Enter）保存。较长的描述会在输入框内滚动并带有滚动条，因此“保存”始终留在屏幕上。两者都只发送自己修改过的内容，所以保存描述不会撤销期间在 GitHub 上进行的重命名。
- 配置文件可以有自己的颜色和图片。在设置 › 提供商中，配置文件的 ⋯ 菜单里有“颜色”（与会话卡片相同的八种颜色）和“选择图片…”，后者接受最大 10 MB 的 PNG、JPEG、GIF 或 WebP，并保留其居中的正方形区域。图片或颜色会显示在所有出现该配置文件的地方：配置文件列表和选择器、侧边栏底部以及“转到”。“移除图片”会回到配置文件颜色上的首字母。

### Changed

- 侧边栏中的卡片块，无论是工作树、文件夹还是置顶块，现在会在第一张卡片打开时渐渐展开，并随最后一张卡片关闭而渐渐收起，而此前它们是瞬间出现和消失的。列表分成多个块时显示的标题也以同样方式展开，在只剩一个块时收起。
- 拉取请求中仍在运行的检查，现在在其“检查”标签页和标签页上方的状态行中显示旋转的指示器，而此前是一个静止的时钟。
- 按钮在按下时不再下沉一个像素，因此窗口中的所有按钮行为一致：原先有这种动效的按钮现在与一直没有这种动效的按钮保持一致。

### Removed

- **Breaking:** 当 `lich open --worktree` 或智能体的 `open_session` 在新工作树中启动会话时，lich 不再运行 `.lich/setup-worktree.sh`。你仓库中的该文件不受影响。如果你的工作树依赖它来安装依赖项，请自行在新工作树的终端中运行它（`sh .lich/setup-worktree.sh`），或者让智能体来运行。复制被 gitignore 忽略的 `.env*` 文件（或 `.worktreeinclude` 中列出的内容）以及开发服务器端口 `LICH_WORKTREE_PORT` 保持不变。

### Fixed

- 智能体的 `git commit`、`rebase` 或 `stash` 不再因为 lich 恰好在同一时刻读取该检出目录的状态或差异，而偶尔失败并提示“Unable to create '.git/index.lock': File exists”。lich 的读取不会触碰索引。
- 已关闭会话的卡片重新会从侧边栏渐渐收起，而此前它是瞬间消失的。
- 在会话中按 Ctrl+Z 不再让其智能体永久冻结。此前它会挂起智能体，而 lich 中没有任何办法将其恢复；现在 lich 不会再把这个按键交给会话。
- 页脚中计划用量提示里的进度条，在 popover 与 muted 颜色相同的主题（例如 Everforest）上重新显示空轨道，此前只绘制了已填充的部分。
- 在拉取请求屏幕上打开或关闭拉取请求列表，不再让当前项目标签页松开其下方的面板后又重新抓住它。标签页全程保持连接，并在列表滑到其下方时移到列表上。
