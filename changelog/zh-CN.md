## [0.76.0] - 2026-10-21

### Added

- 在代码标签页中打开的 Markdown 文件，在“只读”标记旁边有与审查标签页相同的预览按钮，点击后以渲染后的样式（包括表格和链接）显示该文件，取代其源码。再次点击即可回到源码。其他文件仍以源码打开。

### Changed

- 在审查标签页、代码标签页和拉取请求屏幕中，对一批审查评论点击“发送”，会把它们作为提示词发送给会话，而此前它们会停在提示符处等待按下 Enter。Shell 会话会保留这些评论，因为在那里按下 Enter 会把它们当作命令执行。

### Fixed

- 会话终端中的死键现在可以正常组合：在 macOS 上，~ 再按 a 会输入 ã，' 再按 c 会输入 ç，而此前重音符号会先于字母单独出现。输入法仍在组合中的文本，例如日语或中文输入法的，在提交之前也不再传给程序。
- 在 Claude Code 会话中用 `/model` 切换模型后，页脚和会话卡片的提示会在新模型的第一轮结束时就显示新模型。此前它们会一直显示旧模型，直到之后的某一轮或重新连接，原因是 lich 在 Claude Code 写入该轮最后一行之前就读取了转录。
- 在 macOS 上，关闭、最小化和缩放按钮在标题栏中保持居中。此前窗口打开时、切换到其他应用再切回时，以及系统在浅色和深色之间切换时，macOS 会把它们放回标题栏顶部，直到窗口被调整大小。
