## [0.74.0] - 2026-10-20

### Added

- F11 переключает окно в полноэкранный режим и обратно; пока он включён, кнопки «свернуть», «развернуть» и «закрыть» скрыты. Сочетание можно изменить в Настройки › Сочетания клавиш.

### Changed

- Pull request, конфликтующий со своей базовой веткой, больше не перечисляет конфликтующие файлы под заголовком. Статус «Конфликты с» их считает, а щелчок по нему открывает поверх экрана панель, называющую каждый из них.
- **Разрешить конфликты** и **Исправить ошибки CI** в pull request, а также worktree, запущенный из issue `#123`, теперь отправляют своё сообщение в открываемую ими сессию, тогда как раньше оно оставалось в строке ввода и ждало, пока вы нажмёте Enter. Терминальной карточке в этом checkout никогда ничего не отправляется.

### Fixed

- В macOS кнопки «закрыть», «свернуть» и «развернуть» расположены по центру строки заголовка нативного окна, а не прижаты к её верхнему краю, и следуют масштабу интерфейса.
- Окно можно перетаскивать за верхнюю панель: за последней вкладкой и в промежутках вокруг названия и кнопок. Раньше ни одна часть панели его не двигала.
- Экран Pull requests поддерживает показанное актуальным без нажатия «Обновить». Он заново читает pull request каждые несколько секунд, пока GitHub ещё выясняет, можно ли его слить, раз в минуту, пока экран открыт, и когда вы возвращаетесь в окно, поэтому push, слияние или конфликт, сделанные вне lich, появляются сами.
