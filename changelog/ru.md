## [0.71.2] - 2026-10-19

### Fixed

- Нативное окно снова открывается в Windows и macOS, где оно сразу закрывалось,
  ища fontconfig для отрисовки просмотра кода и изменений.
- Эмодзи в терминале нативного окна в Windows рисуются в цвете, а не одними
  контурами.
- Команда обновления, которую lich предлагает для установки на macOS, теперь перед обновлением выполняет tap `lichdotdev/tap`. Установка из старого `omartelo/tap` падала с "Cask 'lichdotdev/tap/lich' is unavailable", потому что Homebrew сам не следует за переехавшим tap; чтобы обновить старый lich, выполните один раз `brew tap lichdotdev/tap`.
- В нативном окне «Раскрывать длинные вставки» теперь раскрывает вставки в Claude Code и Kiro CLI: буфер обмена, пакет комментариев ревью, промпт, с которым pull request или issue открывает сессию, и перетащенные или прикреплённые пути к файлам.
