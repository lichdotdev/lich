## [0.71.2] - 2026-10-19

### Fixed

- ネイティブウィンドウが Windows と macOS で再び開くようになりました。コードと差分の
  ビューを描画するために fontconfig を探して、すぐに閉じていました。
- ネイティブウィンドウのターミナルの絵文字が Windows でカラーで描画されるようになりました。
  これまでは輪郭だけで表示されていました。
- macOS のインストールに提示される更新コマンドは、アップグレードの前に `lichdotdev/tap` を tap するようになりました。旧 `omartelo/tap` からのインストールは "Cask 'lichdotdev/tap/lich' is unavailable" で失敗していました。Homebrew は移動した tap を自動では追わないためです。古い lich からアップグレードするには、一度 `brew tap lichdotdev/tap` を実行してください。
- ネイティブウィンドウで「長い貼り付けを展開」が Claude Code と Kiro CLI の貼り付けを展開するようになりました。対象はクリップボード、まとめて送るレビューコメント、プルリクエストや issue からセッションを開くときのプロンプト、ドロップまたは添付したファイルパスです。
