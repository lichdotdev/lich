## [0.76.0] - 2026-10-21

### Added

- コードタブで開いている Markdown ファイルには、レビュータブと同じプレビューボタンが「読み取り専用」マークの横にあり、ソースの代わりにレンダリングしたファイルを、表やリンクも含めて表示します。もう一度クリックするとソースに戻ります。それ以外のファイルはソースとして開きます。

### Changed

- レビュータブ、コードタブ、プルリクエスト画面で、レビューコメントをまとめて「送信」すると、セッションにプロンプトとして送られます。以前はプロンプトに置かれたまま Enter を待っていました。シェルセッションではコメントはそのまま残ります。Enter を押すとコマンドとして実行されてしまうためです。

### Fixed

- セッションのターミナルでデッドキーが合成されるようになりました。macOS では ~ に続けて a で ã、' に続けて c で ç が入力されます。以前はアクセント記号が文字より先に単独で届いていました。日本語や中国語の IME など、入力メソッドが変換中のテキストも、確定される前にプログラムへ届くことはなくなりました。
- Claude Code セッションで `/model` によってモデルを切り替えたあと、フッターとセッションカードのツールチップには、最初のターンが終わった時点で新しいモデルが表示されます。以前は、Claude Code がそのターンの最後の行を書き込む前に lich がトランスクリプトを読んでいたため、後のターンか再接続まで古いモデルのままでした。
- macOS で、閉じる・最小化・ズームのボタンがタイトルバーの中央に保たれます。以前は、ウィンドウを開いたとき、別のアプリに切り替えて戻ったとき、システムがライトとダークを切り替えたときに、macOS がボタンをバーの上端に戻し、ウィンドウをリサイズするまでそのままでした。
