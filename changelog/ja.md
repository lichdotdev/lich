## [0.70.0] - 2026-10-17

### Added

- **「新機能」があなたの言語で表示されます。** アップデート後に開くダイアログが、リリースノートとそのグループ名を、選択したインターフェースの言語で表示します。両方のウィンドウで対応しています。リリースノートの翻訳がまだないビルドでは、英語で表示されます。
- **ネイティブウィンドウでセッションをフォークできます。** カードを右クリックして「フォーク › ここで」を選ぶと、同じチェックアウトのまま、そのすぐ下の新しいカードで会話を続けられます。「フォーク › ワークツリー…」を選ぶと、未コミットの変更ごと新しいワークツリーに移せます。コピーには元の名前が付き（「auth-refactor 2」）、フォークのマークが表示されます。対応するのは Claude Code、Codex、opencode のみで、それ以外のプロバイダーでは再開のみです。
- **ネイティブウィンドウが、2 枚のカードで 1 つの会話が動いていることを警告します。** エージェント自身の TUI の中から、すでに別のカードで開いている会話を再開すると、右下に警告が表示されます。「切り替える」を押すと、再開したカードが閉じ、その会話を開いていたカードが前面に表示されます。
- **ネイティブウィンドウで画像を表示できます。** PNG、JPEG、GIF、WebP、BMP は、ファイルタブのプレビューに市松模様の背景で表示され、サイズと寸法も確認できます。レビューでは、変更された画像が変更前と変更後を並べて表示されます。PDF など、プレビューのないファイルではエラーの代わりに「既定のアプリで開く」と「フォルダーに表示」が表示されます。プルリクエストでは、バイナリファイルは GitHub 上の該当ファイルへのリンクになります。
- **ネイティブウィンドウがあなたの言語に対応しました。** ネイティブウィンドウのすべての画面が、ポルトガル語、スペイン語、中国語で表示されます。設定 › 一般にはインターフェースの言語とプロンプトの言語があり、ウェブウィンドウでは外観の下にあるものと同じです。選択するまでは、インターフェースはシステムの言語に従います。中国語のフォントがないマシンで中国語を選ぶと、Noto Sans SC（約 25 MB）を lich 専用のフォルダーにダウンロードするかどうかを尋ねます。
- **日本語。** 両方のウィンドウが日本語で表示され、日本語はプロンプトの言語にもなるため、lich はエージェントに日本語で話しかけます。ネイティブウィンドウは、日本語・中国語・韓国語をそれぞれの地域のフォントで描画します（インストールされていれば。Noto Sans CJK、Yu Gothic、Hiragino、Malgun Gothic など）。そのため漢字が中国語の字形になることはなくなりました。該当するフォントがない場合は、中国語の Noto Sans SC と同様に、Noto Sans JP または KR をダウンロードするかどうかを尋ねます。README も日本語になりました。
- **韓国語。** 両方のウィンドウが韓国語で表示されます。ウェブでは設定 › 外観、ネイティブウィンドウでは設定 › 一般で選べます。韓国語はプロンプトの言語にもなり、ブリーフィング、中継されたメッセージ、通知がエージェントに韓国語で届きます。
- **lich がロシア語に対応しました。** Русский をインターフェースの言語として選べます。ウェブウィンドウでは設定 › 外観、ネイティブウィンドウでは設定 › 一般にあります。プロンプトの言語としても選べるため、lich がエージェントに入力するブリーフィング、中継メモ、引き継ぎもロシア語になります。数はロシア語の one、few、many の 3 つの形に従います（1 файл、2 файла、5 файлов）。
- **macOS と Windows での opencode プロファイル、Windows での Cursor CLI プロファイル。** ネイティブウィンドウの設定 › プロバイダーに、Linux と同様に一覧表示されます。macOS の Cursor CLI と、macOS および Windows の Kiro CLI には、引き続きありません。これらではログイン情報が Keychain、または設定では移せないフォルダーに保存されるため、どのプロファイルも 1 つのアカウントを共有することになります。

### Changed

- **アップデートのたびにネイティブウィンドウが開きます。** 各リリースの初回起動で lich はネイティブウィンドウに切り替わり、起動できない場合はウェブウィンドウにフォールバックします。設定で切り替え直すと、次のリリースまで lich はウェブウィンドウのままです。ネイティブウィンドウが初めて開くときは、実験的であることを知らせ、バグ報告へのリンクを表示します。
- **ネイティブウィンドウのステータスリングが細くなりました。** セッションカードのアイコンを囲むリングがより細く描画され、ウェブウィンドウと同じ太さで表示されます。
- **ネイティブウィンドウのショートカットキーの余白が広くなりました。** コマンドパレット、ショートカットの一覧、設定 › ショートカットのキーキャップは、文字の周りの余白が広くなり、文字は中央に配置されます。
- **ネイティブウィンドウの設定は「グローバル」で開きます。** 上部バーの歯車は、最後に開いていたスコープではなく、常に「グローバル」で設定を開きます。プロジェクトのタブから「プロジェクト設定…」を選ぶと、引き続きそのプロジェクトの設定が開きます。
- **ネイティブウィンドウのコマンドパレットがすっきりしました。** セッション、プロジェクト、メッセージは 1 行で表示され、名前の後にパスが付きます。ワークツリーのパスは最後の 3 つの要素を表示します。あなたの応答を待っているセッションが先頭に並び、その旨が表示されます。フィルタータブはピルをやめて下線になりました。履歴の閉じたセッションは、右側にブランチと経過時間を表示し、検索が会話に一致したときだけ 2 行目を追加して、該当する語を強調します。

### Fixed

- **再起動したセッションが、ずっと処理中のままに見えなくなりました。** ターンの途中でエージェントが終了したセッションや、ターンの途中で閉じられたセッションは、同じカードのまま戻ってきても、ほかのセッションからは処理中と表示されていました。そのセッションに送ったタスクは、終わることのないターンを待ち続けていました。現在は新しいセッションと同じく、状態のない状態で開始します。
- **Codex、Cursor CLI、Antigravity、Crush が、すでに答えた質問を繰り返さなくなりました。** これらのいずれかのサンドボックス化されたセッションは、そのままプロンプトで開きます。Cursor CLI と Antigravity は、信頼済みのフォルダーのワークツリーで再度尋ねなくなり、Antigravity はそのサブフォルダーでも尋ねなくなりました。Crush も新しいワークツリーごとに初期化を尋ねなくなりました。サンドボックス化された oh-my-pi のセッションも、セットアップウィザードで開かなくなりました。
- **Claude Code が、すでに答えた「このフォルダーを信頼しますか？」を尋ねなくなりました。** メインのアカウントで信頼したフォルダーは、ほかのすべての Claude Code プロファイルでも、そこでの次のセッションから信頼されます。サンドボックス化された Claude Code のセッションは、この質問なしで開きます。lich が開いたセッションが、Enter で終了してしまうこの画面で止まることもなくなりました。
- **再び開いたネイティブウィンドウが、各セッションの移動先を把握するようになりました。** `cd` や tmux、ssh で移動していたセッションが、次の `cd` までチェックアウトのパス、ブランチ、変更を表示したまま戻ってくることがありました。現在はウィンドウが接続時に、各セッションの最後の場所を読み取ります。
- **ネイティブウィンドウが、エージェントへのプロンプトをプロンプトの言語で書くようになりました。** プルリクエストと issue の引き継ぎ、およびレビューコメントのまとめが、常に英語で入力されていました。
- **再接続中にテーマを変更してもネイティブウィンドウがクラッシュしなくなりました。** ウィンドウが再起動した lich に再接続している間にテーマを切り替えたり、システムがライトとダークを切り替えたりすると、再接続で解放されたばかりのターミナルを描画してしまい、ウィンドウが落ちることがありました。
- **中国語・日本語・韓国語のテキストで、Linux のネイティブウィンドウがフリーズしなくなりました。** CJK のテキストが大量にあるセッション、レビュー、プルリクエストでは、ウィンドウが数秒間ハングして「応答なし」になることがあり、ズームするとフリーズが再発していました。
- **ネイティブウィンドウのメモリ使用量が減りました。** 各セッションのターミナルとレビューが、フォールバック先のフォントをそれぞれ独自に読み込んでいました。CJK や絵文字のフォントでは 1 つにつき数十 MB です。現在は 6 つのセッションを開いたときのメモリ使用量が約半分になりました。CJK フォントがインストールされているマシンでは、起動も速くなりました。
- **会話がすでに開いているセッションを再び開くと、そのカードにフォーカスします。** 履歴から閉じたセッションを開いたとき、閉じる操作を元に戻したとき、既存のワークツリーを開いたときに、別のカードがまだ実行している会話に 2 枚目のカードが作られ、2 つが同じトランスクリプトに書き込むことがありました。履歴にはそのような会話が最新の終了分だけ 1 件表示され、「履歴から削除」はそのすべてのコピーを削除します。
