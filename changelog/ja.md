## [0.73.0] - 2026-10-20

> [!IMPORTANT]
> **全員へ: ネイティブウィンドウが lich 唯一のウィンドウになりました。** lich は起動のたびにネイティブウィンドウを開きます。Web ウィンドウと組み込みの Chromium はなくなりました。

### Added

- **Windows と macOS のネイティブウィンドウで、クリックできるデスクトップ通知。** Linux と同様に、入力を待っているセッションやターンを終えたセッションが、開く・閉じるボタン付きの通知を出します。開くを押すとそのセッションのカードで lich が前面に出て、セッションに応答するか開くと通知は消えます。macOS では Lich.app から lich を起動する必要があり、初回に一度だけ許可を求められます。Windows では、あなたを待っているセッションの通知は操作するまで画面に残ります。
- 独自のバイナリ経由でセッションを起動している場合、設定 › プロバイダーのプロファイルの下に警告を表示します。バイナリのパスと、それを表示するボタン、既定に戻すボタンも並びます。独自のログインや設定ディレクトリを指定するラッパーはプロファイルより優先され、バイナリの設定は画面の下部に折りたたまれています。

### Changed

- セッションのプロセスが終了すると、ターミナル下部の帯の代わりに、右下のトースト通知で次の操作を尋ねるようになりました。会話のあるカードには、同じ会話をもう一度開く再開（開始時のプロファイルで開きます）、再起動と同じようにカード内で別の会話を始める新しく始める、セッションを閉じるが表示されます。シェルや、最初のプロンプトの前に終了したエージェントには、再起動とセッションを閉じるが表示されます。トーストを閉じるとカードはそのままになり、カードにフォーカスするとトーストが再表示されます。
- **プロジェクトのプロファイルは、各カードではなくサイドバーの下部に表示されます。** プロバイダーに複数のログインがある場合、サイドバーの最終行に、このプロジェクトでそのプロバイダーの新しいセッションが起動するプロファイルが表示されます。画面に表示中のカードのプロバイダー、ターミナルの場合は既定のものです。クリックすると、5 時間の使用量付きで別のログインを選べ、グローバルのものに戻すこともできます。その他のプロバイダーは同じメニューから変更できます。カードのブランチの横にプロファイルのチップは表示されなくなりました。

### Removed

- Web ウィンドウ。lich はネイティブウィンドウを開き、リリースに Chromium は含まれなくなりました。設定のウィンドウの選択（Web かネイティブ）と、もう一方のウィンドウを開いていたトレイ項目はなくなり、`lich -- <chromium flags>`、`lich --shell`、`LICH_SHELL` も使えなくなりました。ネイティブウィンドウを起動できない場合、lich は理由とログの場所を表示します。

### Fixed

- Claude Code や Codex のプロファイルでログインするとき、ブラウザでの操作が終わった時点、または貼り付けたコードを送信した時点で、認証中であることが表示されるようになりました。以前はダイアログが最後までログインを待ち続け、コード欄が空になるだけでした。
- ブラジルポルトガル語で、すべてのメッセージが worktree を "a worktree" と呼ぶようになりました。一部は "o worktree" になっていました。
- macOS で、ネイティブウィンドウに閉じる・最小化・ズームのボタンが戻りました。0.72.0 以降、トップバーにその場所が空いたままになっていました。
- Windows で、ネイティブウィンドウからの lich のアップデートが "Setup was unable to automatically close all applications" でロールバックしなくなりました。ウィンドウが、インストーラーが置き換える必要のある `lich-native.exe` の上で開いたままになっていたためです。今はインストーラーの実行前に閉じ、lich が戻ると再び開きます。0.72.0 以前からのアップデートでは一度だけ発生します。メッセージが出たらタスクマネージャーで `lich-native.exe` を終了し、Retry を選び、その後スタートメニューから lich を開いてください。
- lich が終了した後や再起動中など、lich が不在のときにネイティブウィンドウを閉じると、ウィンドウを閉じたときの設定にかかわらず閉じるようになりました。確認するや終了のときは、ウィンドウが開いたままで、セッションを数えられなかったというエラーだけが表示されていました。
- 幅の狭い設定ウィンドウで、プロバイダーのプロファイルの選択のように、コントロールが広すぎて同じ行に収まらない設定は、コントロールをタイトルと説明の下に置くようになりました。以前は文章が細く押しつぶされ、1 文字ずつ折り返されていました。プロバイダーのドキュメントのリンクも、有効のスイッチに食い込まず、名前の下に移動します。
- セッション終了後も動き続けたプラグインのフック（たとえば WakaTime のもの）がファイルを残し、移動が "already holds" で拒否されることがありましたが、次で続けるで Claude Code の会話を直前に離れたプロファイルへ戻せるようになりました。
