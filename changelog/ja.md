## [0.76.0] - 2026-10-21

### Fixed

- セッションのターミナルでデッドキーが合成されるようになりました。macOS では ~ に続けて a で ã、' に続けて c で ç が入力されます。以前はアクセント記号が文字より先に単独で届いていました。日本語や中国語の IME など、入力メソッドが変換中のテキストも、確定される前にプログラムへ届くことはなくなりました。

- macOS で、閉じる・最小化・ズームのボタンがタイトルバーの中央に保たれます。以前は、ウィンドウを開いたとき、別のアプリに切り替えて戻ったとき、システムがライトとダークを切り替えたときに、macOS がボタンをバーの上端に戻し、ウィンドウをリサイズするまでそのままでした。

## [0.75.0] - 2026-10-21

### Added

- レビュータブの Markdown ファイルには、「ファイルをコンテキストとして追加」の横にプレビューボタンがあり、差分の代わりにレンダリングしたファイルを、表やリンクも含めて表示します。もう一度クリックすると差分に戻ります。プルリクエスト画面では、そのプルリクエストが追加したファイルにだけ表示されます。
- コードタブで開いているファイルで Ctrl+F（macOS では Cmd+F）を押すと、ファイル内のテキストを検索できます。ファイル名の下に表示されるバーが一致箇所をすべて強調し、Enter と Shift+Enter で順に移動でき、大文字と小文字の区別、単語単位、正規表現にも対応します。バーの一覧ボタンは、一致のある行をバーの下にすべて表示し、クリックするとコードのその位置へ移動します。Escape で閉じます。
- セッションカードのツールチップに、セッションが実行しているモデルが表示されます。対象は Claude Code、Codex、Kiro CLI です。たとえば `/model` の後などで、セッションを開いたときのモデルと異なる場合は、「…で開始、…で実行中」と表示されます。
- プルリクエスト画面で、プルリクエストのタイトルと説明を編集して GitHub に送信できます。タイトルの後ろの鉛筆アイコンでその場で名前を変更でき、Enter か別の場所のクリックで保存、Escape でキャンセルします。概要の説明の横の編集を押すと Markdown として開き、保存か Ctrl+Enter（macOS では Cmd+Enter）で保存します。長い説明はスクロールバーつきでフィールド内をスクロールするので、保存ボタンは画面に残ります。どちらも変更した内容だけを送信するため、説明を保存しても、その間に GitHub で行った名前変更が元に戻ることはありません。
- プロファイルに独自の色と画像を設定できます。設定 › プロバイダーで、プロファイルの ⋯ メニューに、セッションカードと同じ 8 色から選べる「色」と、10 MB までの PNG、JPEG、GIF、WebP を受け付け、中央の正方形を使う「画像を選択…」が加わりました。画像または色は、プロファイルが表示される場所すべてに反映されます。プロファイルの一覧と選択画面、サイドバーのフッター、「次で続ける」です。「画像を削除」を選ぶと、プロファイルの色の上にイニシャルを表示する状態に戻ります。

### Changed

- サイドバーのカードのまとまり（worktree、フォルダー、ピン留めのブロック）は、最初のカードが開くと徐々に広がり、最後のカードが閉じると徐々に縮むようになりました。以前は一瞬で現れて消えていました。リストがブロックに分かれたときに表示される見出しも同じように開き、1 つだけになると畳まれます。
- 実行中のチェックがあるプルリクエストでは、チェックタブと、タブの上のステータス行で、止まった時計の代わりにスピナーが回ります。
- ボタンを押している間に 1 ピクセル沈むことがなくなり、ウィンドウ内のすべてのボタンが同じ動作になりました。この動きがあったボタンを、なかったボタンに合わせています。

### Removed

- **互換性を損なう変更：** `lich open --worktree` やエージェントの `open_session` が新しい worktree でセッションを開始するとき、lich は `.lich/setup-worktree.sh` を実行しなくなりました。リポジトリ内のファイルはそのままです。worktree が依存関係のインストールにこのファイルを使っていた場合は、新しい worktree のターミナルで自分で実行する（`sh .lich/setup-worktree.sh`）か、エージェントに頼んでください。gitignore 対象の `.env*` ファイル（または `.worktreeinclude` が指定するもの）のコピーと、`LICH_WORKTREE_PORT` の開発サーバーポートは変わりません。

### Fixed

- lich がちょうど同じ時にそのチェックアウトのステータスや差分を読んでいたせいで、エージェントの `git commit`、`rebase`、`stash` が「Unable to create '.git/index.lock': File exists」で時々失敗する問題を修正しました。lich の読み取りはインデックスに触れません。
- 閉じたセッションのカードが、一瞬で消えるのではなく、サイドバーから再び徐々に縮んで消えるようになりました。
- セッションで Ctrl+Z を押しても、エージェントが永久に固まらなくなりました。以前はエージェントが一時停止され、lich からは元に戻せませんでした。lich はこのキーをセッションに渡さないようにしました。
- フッターのプラン使用量ツールチップのバーが、Everforest のようにポップオーバーとミュートの色が同じテーマでも、空のトラックを再び表示するようになりました。以前は塗りつぶされた部分だけが描かれていました。
- プルリクエスト画面でプルリクエストの一覧を開閉しても、アクティブなプロジェクトタブがすぐ下のパネルから離れて再び接続することがなくなりました。タブはずっと接続されたままで、一覧が下にスライドしてきた時点でその上に移ります。

## [0.73.0] - 2026-10-20

> [!IMPORTANT]
> **全員へ: ネイティブウィンドウが lich 唯一のウィンドウになりました。** lich は起動のたびにネイティブウィンドウを開きます。Web ウィンドウと組み込みの Chromium はなくなりました。

### Added

- **Windows と macOS のネイティブウィンドウで、クリックできるデスクトップ通知。** Linux と同様に、入力を待っているセッションやターンを終えたセッションが、開く・閉じるボタン付きの通知を出します。開くを押すとそのセッションのカードで lich が前面に出て、セッションに応答するか開くと通知は消えます。macOS では Lich.app から lich を起動する必要があり、初回に一度だけ許可を求められます。Windows では、あなたを待っているセッションの通知は操作するまで画面に残ります。
- 独自のバイナリ経由でセッションを起動している場合、設定 › プロバイダーのプロファイルの下に警告を表示します。バイナリのパスと、それを表示するボタン、既定に戻すボタンも並びます。独自のログインや設定ディレクトリを指定するラッパーはプロファイルより優先され、バイナリの設定は画面の下部に折りたたまれています。

### Changed

- セッションのプロセスが終了すると、ターミナル下部の帯の代わりに、右下のトースト通知で次の操作を尋ねるようになりました。会話のあるカードには、同じ会話をもう一度開く再開（開始時のプロファイルで開きます）、再起動と同じようにカード内で別の会話を始める新しく始める、セッションを閉じるが表示されます。シェルや、最初のプロンプトの前に終了したエージェントには、再起動とセッションを閉じるが表示されます。トーストを閉じるとカードはそのままになり、カードにフォーカスするとトーストが再表示されます。
- **プロジェクトのプロファイルは、各カードではなくサイドバーの下部に表示されます。** プロバイダーに複数のログインがある場合、サイドバーの最終行に、このプロジェクトでそのプロバイダーの新しいセッションが起動するプロファイルが表示されます。画面に表示中のカードのプロバイダー、ターミナルの場合は既定のものです。クリックすると、5 時間の使用量付きで別のログインを選べ、グローバルのものに戻すこともできます。その他のプロバイダーは同じメニューから変更できます。カードのブランチの横にプロファイルのチップは表示されなくなりました。

### Removed

- Web ウィンドウ。lich はネイティブウィンドウを開き、リリースに Chromium は含まれなくなりました。設定のウィンドウの選択（Web かネイティブ）と、もう一方のウィンドウを開いていたトレイ項目はなくなり、`lich -- <chromium flags>`、`lich --shell`、`LICH_SHELL` も使えなくなりました。ネイティブウィンドウを起動できない場合、lich は理由とログの場所を表示します。

### Fixed

- Claude Code や Codex のプロファイルでログインするとき、ブラウザでの操作が終わった時点、または貼り付けたコードを送信した時点で、認証中であることが表示されるようになりました。以前はダイアログが最後までログインを待ち続け、コード欄が空になるだけでした。
- ブラジルポルトガル語で、すべてのメッセージが worktree を "a worktree" と呼ぶようになりました。一部は "o worktree" になっていました。
- macOS で、ネイティブウィンドウに閉じる・最小化・ズームのボタンが戻りました。0.72.0 以降、トップバーにその場所が空いたままになっていました。
- Windows で、ネイティブウィンドウからの lich のアップデートが "Setup was unable to automatically close all applications" でロールバックしなくなりました。ウィンドウが、インストーラーが置き換える必要のある `lich-native.exe` の上で開いたままになっていたためです。今はインストーラーの実行前に閉じ、lich が戻ると再び開きます。0.72.0 以前からのアップデートでは一度だけ発生します。メッセージが出たらタスクマネージャーで `lich-native.exe` を終了し、Retry を選び、その後スタートメニューから lich を開いてください。
- lich が終了した後や再起動中など、lich が不在のときにネイティブウィンドウを閉じると、ウィンドウを閉じたときの設定にかかわらず閉じるようになりました。確認するや終了のときは、ウィンドウが開いたままで、セッションを数えられなかったというエラーだけが表示されていました。
- 幅の狭い設定ウィンドウで、プロバイダーのプロファイルの選択のように、コントロールが広すぎて同じ行に収まらない設定は、コントロールをタイトルと説明の下に置くようになりました。以前は文章が細く押しつぶされ、1 文字ずつ折り返されていました。プロバイダーのドキュメントのリンクも、有効のスイッチに食い込まず、名前の下に移動します。
- セッション終了後も動き続けたプラグインのフック（たとえば WakaTime のもの）がファイルを残し、移動が "already holds" で拒否されることがありましたが、次で続けるで Claude Code の会話を直前に離れたプロファイルへ戻せるようになりました。

- **ネイティブウィンドウでセッションをフォークできます。** カードを右クリックして「フォーク › ここで」を選ぶと、同じチェックアウトのまま、そのすぐ下の新しいカードで会話を続けられます。「フォーク › ワークツリー…」を選ぶと、未コミットの変更ごと新しいワークツリーに移せます。コピーには元の名前が付き（「auth-refactor 2」）、フォークのマークが表示されます。対応するのは Claude Code、Codex、opencode のみで、それ以外のプロバイダーでは再開のみです。
- **ネイティブウィンドウが、2 枚のカードで 1 つの会話が動いていることを警告します。** エージェント自身の TUI の中から、すでに別のカードで開いている会話を再開すると、右下に警告が表示されます。「切り替える」を押すと、再開したカードが閉じ、その会話を開いていたカードが前面に表示されます。
- **ネイティブウィンドウで画像を表示できます。** PNG、JPEG、GIF、WebP、BMP は、ファイルタブのプレビューに市松模様の背景で表示され、サイズと寸法も確認できます。レビューでは、変更された画像が変更前と変更後を並べて表示されます。PDF など、プレビューのないファイルではエラーの代わりに「既定のアプリで開く」と「フォルダーに表示」が表示されます。プルリクエストでは、バイナリファイルは GitHub 上の該当ファイルへのリンクになります。
- **ネイティブウィンドウがあなたの言語に対応しました。** ネイティブウィンドウのすべての画面が、ポルトガル語、スペイン語、中国語で表示されます。設定 › 一般にはインターフェースの言語とプロンプトの言語があり、ウェブウィンドウでは外観の下にあるものと同じです。選択するまでは、インターフェースはシステムの言語に従います。中国語のフォントがないマシンで中国語を選ぶと、Noto Sans SC（約 25 MB）を lich 専用のフォルダーにダウンロードするかどうかを尋ねます。
- **日本語。** 両方のウィンドウが日本語で表示され、日本語はプロンプトの言語にもなるため、lich はエージェントに日本語で話しかけます。ネイティブウィンドウは、日本語・中国語・韓国語をそれぞれの地域のフォントで描画します（インストールされていれば。Noto Sans CJK、Yu Gothic、Hiragino、Malgun Gothic など）。そのため漢字が中国語の字形になることはなくなりました。該当するフォントがない場合は、中国語の Noto Sans SC と同様に、Noto Sans JP または KR をダウンロードするかどうかを尋ねます。README も日本語になりました。
- **韓国語。** 両方のウィンドウが韓国語で表示されます。ウェブでは設定 › 外観、ネイティブウィンドウでは設定 › 一般で選べます。韓国語はプロンプトの言語にもなり、ブリーフィング、中継されたメッセージ、通知がエージェントに韓国語で届きます。
- **lich がロシア語に対応しました。** Русский をインターフェースの言語として選べます。ウェブウィンドウでは設定 › 外観、ネイティブウィンドウでは設定 › 一般にあります。プロンプトの言語としても選べるため、lich がエージェントに入力するブリーフィング、中継メモ、引き継ぎもロシア語になります。数はロシア語の one、few、many の 3 つの形に従います（1 файл、2 файла、5 файлов）。
- **macOS と Windows での opencode プロファイル、Windows での Cursor CLI プロファイル。** ネイティブウィンドウの設定 › プロバイダーに、Linux と同様に一覧表示されます。macOS の Cursor CLI と、macOS および Windows の Kiro CLI には、引き続きありません。これらではログイン情報が Keychain、または設定では移せないフォルダーに保存されるため、どのプロファイルも 1 つのアカウントを共有することになります。

### Changed

- **アップデートのたびにネイティブウィンドウが開きます。** 各リリースの初回起動で lich はネイティブウィンドウに切り替わり、起動できない場合はウェブウィンドウにフォールバックします。設定で切り替え直すと、次のリリースまで lich はウェブウィンドウのままです。ネイティブウィンドウが初めて開くときは、実験的であることを知らせ、バグ報告へのリンクを表示します。
- **ネイティブウィンドウのステータスリングが細くなりました。** セッションカードのアイコンを囲むリングがより細く描画され、ウェブウィンドウと同じ太さで表示されます。
- **ネイティブウィンドウのショートカットキーの余白が広くなりました。** コマンドパレット、ショートカットの一覧、設定 › ショートカットのキーキャップは、文字の周りの余白が広くなり、文字は中央に配置されます。
- **ネイティブウィンドウの設定は「グローバル」で開きます。** 上部バーの歯車は、最後に開いていたスコープではなく、常に「グローバル」で設定を開きます。プロジェクトのタブから「プロジェクト設定…」を選ぶと、引き続きそのプロジェクトの設定が開きます。
- **ネイティブウィンドウのコマンドパレットがすっきりしました。** セッション、プロジェクト、メッセージは 1 行で表示され、名前の後にパスが付きます。ワークツリーのパスは最後の 3 つの要素を表示します。あなたの応答を待っているセッションが先頭に並び、その旨が表示されます。フィルタータブはピルをやめて下線になりました。履歴の閉じたセッションは、右側にブランチと経過時間を表示し、検索が会話に一致したときだけ 2 行目を追加して、該当する語を強調します。

### Fixed

- **再起動したセッションが、ずっと処理中のままに見えなくなりました。** ターンの途中でエージェントが終了したセッションや、ターンの途中で閉じられたセッションは、同じカードのまま戻ってきても、ほかのセッションからは処理中と表示されていました。そのセッションに送ったタスクは、終わることのないターンを待ち続けていました。現在は新しいセッションと同じく、状態のない状態で開始します。
- **Codex、Cursor CLI、Antigravity、Crush が、すでに答えた質問を繰り返さなくなりました。** これらのいずれかのサンドボックス化されたセッションは、そのままプロンプトで開きます。Cursor CLI と Antigravity は、信頼済みのフォルダーのワークツリーで再度尋ねなくなり、Antigravity はそのサブフォルダーでも尋ねなくなりました。Crush も新しいワークツリーごとに初期化を尋ねなくなりました。サンドボックス化された oh-my-pi のセッションも、セットアップウィザードで開かなくなりました。
- **Claude Code が、すでに答えた「このフォルダーを信頼しますか？」を尋ねなくなりました。** メインのアカウントで信頼したフォルダーは、ほかのすべての Claude Code プロファイルでも、そこでの次のセッションから信頼されます。サンドボックス化された Claude Code のセッションは、この質問なしで開きます。lich が開いたセッションが、Enter で終了してしまうこの画面で止まることもなくなりました。
- **再び開いたネイティブウィンドウが、各セッションの移動先を把握するようになりました。** `cd` や tmux、ssh で移動していたセッションが、次の `cd` までチェックアウトのパス、ブランチ、変更を表示したまま戻ってくることがありました。現在はウィンドウが接続時に、各セッションの最後の場所を読み取ります。
- **ネイティブウィンドウが、エージェントへのプロンプトをプロンプトの言語で書くようになりました。** プルリクエストと issue の引き継ぎ、およびレビューコメントのまとめが、常に英語で入力されていました。
- **再接続中にテーマを変更してもネイティブウィンドウがクラッシュしなくなりました。** ウィンドウが再起動した lich に再接続している間にテーマを切り替えたり、システムがライトとダークを切り替えたりすると、再接続で解放されたばかりのターミナルを描画してしまい、ウィンドウが落ちることがありました。
- **中国語・日本語・韓国語のテキストで、Linux のネイティブウィンドウがフリーズしなくなりました。** CJK のテキストが大量にあるセッション、レビュー、プルリクエストでは、ウィンドウが数秒間ハングして「応答なし」になることがあり、ズームするとフリーズが再発していました。
- **ネイティブウィンドウのメモリ使用量が減りました。** 各セッションのターミナルとレビューが、フォールバック先のフォントをそれぞれ独自に読み込んでいました。CJK や絵文字のフォントでは 1 つにつき数十 MB です。現在は 6 つのセッションを開いたときのメモリ使用量が約半分になりました。CJK フォントがインストールされているマシンでは、起動も速くなりました。
- **会話がすでに開いているセッションを再び開くと、そのカードにフォーカスします。** 履歴から閉じたセッションを開いたとき、閉じる操作を元に戻したとき、既存のワークツリーを開いたときに、別のカードがまだ実行している会話に 2 枚目のカードが作られ、2 つが同じトランスクリプトに書き込むことがありました。履歴にはそのような会話が最新の終了分だけ 1 件表示され、「履歴から削除」はそのすべてのコピーを削除します。

## [0.69.0] - 2026-10-16

### Added

- **macOS でネイティブウィンドウを利用可能に（実験的）。** Lich.app は Apple Silicon と Intel の両方で lich と並べてネイティブウィンドウを同梱しており、Linux や Windows と同じく設定 › 外観 › ウィンドウから選べます。ターミナルでは Option キーが文字入力に使われます（Terminal.app と同じ動作）。そのため、エージェントの Option+文字 のショートカットは届きません。これまでのところ GitHub の macOS マシンでしか動作しておらず、通知はクリックできない通常の通知で、メニューバー項目もありません。
- **ファイルツリーが対応するファイル形式が大幅に増えました。** Java、Gradle、C と C++、C#、PHP、Ruby、Swift、SQL、Vue、Svelte、Terraform、Dockerfile、.gitignore のほか約 30 種類が、これまでの無地のファイルアイコンに代わって、ファイルツリーと検索結果で専用のアイコンで表示されます。

### Fixed

- **`lich quit` がネイティブウィンドウを閉じるようになりました。** バックエンドが終了したあとも、ウィンドウは lich を接続切れとして表示したまま開いたままでした。トレイの終了や停止シグナルでも閉じます。一方、アップデート後の再起動ではウィンドウは維持されます。
- **ネイティブウィンドウで、最後のセッションを閉じたときにワークツリーを削除できるようになりました。** 「閉じました」トーストに「元に戻す」と並んで「ワークツリーを削除」が加わります。lich が作成していないワークツリーや未コミットの変更があるワークツリーは、削除する前にダイアログで知らされます。

- **ネイティブウィンドウのターミナルが、ポインターの下のセルを正しく扱うようになりました。** クリック、ドラッグ選択、リンク、マウスを追跡するプログラムのいずれも、ターミナルのパディング分ずれた位置のポインターを読み取っていたため、実際に指しているセルの右下のセルが対象になっていました。スケーリングされたディスプレイでは、そのずれはほぼセル 1 つ分でした。
- **ネイティブウィンドウのターミナルが絵文字を描画するようになりました。** Noto Color Emoji などのカラー絵文字フォントは、各絵文字をアウトラインではなく画像として保持しています。ターミナルはアウトラインしか描画しなかったため、すべての絵文字が空白になっていました。現在は 2 セル幅のカラーで描画されます。
- **ネイティブウィンドウのファイルツリーが、ファイルごとの言語アイコンを表示するようになりました。** これまではどのファイルも同じ無地のファイルアイコンでしたが、ブラウザウィンドウと同じアイコンが付きます。
