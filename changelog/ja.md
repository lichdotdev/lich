## [0.75.0] - 2026-10-21

### Added

- レビュータブの Markdown ファイルには、「ファイルをコンテキストとして追加」の横にプレビューボタンがあり、差分の代わりにレンダリングしたファイルを、表やリンクも含めて表示します。もう一度クリックすると差分に戻ります。プルリクエスト画面では、そのプルリクエストが追加したファイルにだけ表示されます。
- コードタブで開いているファイルで Ctrl+F（macOS では Cmd+F）を押すと、ファイル内のテキストを検索できます。ファイル名の下に表示されるバーが一致箇所をすべて強調し、Enter と Shift+Enter で順に移動でき、大文字と小文字の区別、単語単位、正規表現にも対応します。バーの一覧ボタンは、一致のある行をバーの下にすべて表示し、クリックするとコードのその位置へ移動します。Escape で閉じます。
- セッションカードのツールチップに、セッションが実行しているモデルが表示されます。対象は Claude Code、Codex、Kiro CLI です。たとえば `/model` の後などで、セッションを開いたときのモデルと異なる場合は、「…で開始、…で実行中」と表示されます。
- プルリクエスト画面で、プルリクエストのタイトルと説明を編集して GitHub に送信できます。タイトルの後ろの鉛筆アイコンでその場で名前を変更でき、Enter か別の場所のクリックで保存、Escape でキャンセルします。概要の説明の横の編集を押すと Markdown として開き、保存か Ctrl+Enter（macOS では Cmd+Enter）で保存します。長い説明はスクロールバーつきでフィールド内をスクロールするので、保存ボタンは画面に残ります。どちらも変更した内容だけを送信するため、説明を保存しても、その間に GitHub で行った名前変更が元に戻ることはありません。
- プロファイルに独自の色と画像を設定できます。設定 › プロバイダーで、プロファイルの ⋯ メニューに、セッションカードと同じ 8 色から選べる「色」と、10 MB までの PNG、JPEG、GIF、WebP を受け付け、中央の正方形を使う「画像を選択…」が加わりました。画像または色は、プロファイルが表示される場所すべてに反映されます。プロファイルの一覧と選択画面、サイドバーのフッター、「次で続ける」です。「画像を削除」を選ぶと、プロファイルの色の上にイニシャルを表示する状態に戻ります。

### Changed

- サイドバーのカードのまとまり（worktree、フォルダー、ピン留めのブロック）は、最初のカードが開くと徐々に広がり、最後のカードが閉じると徐々に縮むようになりました。以前は一瞬で現れて消えていました。リストがブロックに分かれたときに表示される見出しも同じように開き、1 つだけになると畳まれます。
- 実行中のチェックがあるプルリクエストでは、チェックタブと、タブの上のステータス行で、止まった時計の代わりにスピナーが回ります。
- ボタンを押している間に 1 ピクセル沈むことがなくなり、ウィンドウ内のすべてのボタンが同じ動作になりました。この動きがあったボタンを、なかったボタンに合わせています。

### Removed

- **互換性を損なう変更：** `lich open --worktree` やエージェントの `open_session` が新しい worktree でセッションを開始するとき、lich は `.lich/setup-worktree.sh` を実行しなくなりました。リポジトリ内のファイルはそのままです。worktree が依存関係のインストールにこのファイルを使っていた場合は、新しい worktree のターミナルで自分で実行する（`sh .lich/setup-worktree.sh`）か、エージェントに頼んでください。gitignore 対象の `.env*` ファイル（または `.worktreeinclude` が指定するもの）のコピーと、`LICH_WORKTREE_PORT` の開発サーバーポートは変わりません。

### Fixed

- lich がちょうど同じ時にそのチェックアウトのステータスや差分を読んでいたせいで、エージェントの `git commit`、`rebase`、`stash` が「Unable to create '.git/index.lock': File exists」で時々失敗する問題を修正しました。lich の読み取りはインデックスに触れません。
- 閉じたセッションのカードが、一瞬で消えるのではなく、サイドバーから再び徐々に縮んで消えるようになりました。
- セッションで Ctrl+Z を押しても、エージェントが永久に固まらなくなりました。以前はエージェントが一時停止され、lich からは元に戻せませんでした。lich はこのキーをセッションに渡さないようにしました。
- フッターのプラン使用量ツールチップのバーが、Everforest のようにポップオーバーとミュートの色が同じテーマでも、空のトラックを再び表示するようになりました。以前は塗りつぶされた部分だけが描かれていました。
- プルリクエスト画面でプルリクエストの一覧を開閉しても、アクティブなプロジェクトタブがすぐ下のパネルから離れて再び接続することがなくなりました。タブはずっと接続されたままで、一覧が下にスライドしてきた時点でその上に移ります。
