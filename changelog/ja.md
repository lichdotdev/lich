## [0.69.0] - 2026-10-16

### Added

- **macOS でネイティブウィンドウを利用可能に（実験的）。** Lich.app は Apple Silicon と Intel の両方で lich と並べてネイティブウィンドウを同梱しており、Linux や Windows と同じく設定 › 外観 › ウィンドウから選べます。ターミナルでは Option キーが文字入力に使われます（Terminal.app と同じ動作）。そのため、エージェントの Option+文字 のショートカットは届きません。これまでのところ GitHub の macOS マシンでしか動作しておらず、通知はクリックできない通常の通知で、メニューバー項目もありません。
- **ファイルツリーが対応するファイル形式が大幅に増えました。** Java、Gradle、C と C++、C#、PHP、Ruby、Swift、SQL、Vue、Svelte、Terraform、Dockerfile、.gitignore のほか約 30 種類が、これまでの無地のファイルアイコンに代わって、ファイルツリーと検索結果で専用のアイコンで表示されます。

### Fixed

- **`lich quit` がネイティブウィンドウを閉じるようになりました。** バックエンドが終了したあとも、ウィンドウは lich を接続切れとして表示したまま開いたままでした。トレイの終了や停止シグナルでも閉じます。一方、アップデート後の再起動ではウィンドウは維持されます。
- **ネイティブウィンドウで、最後のセッションを閉じたときにワークツリーを削除できるようになりました。** 「閉じました」トーストに「元に戻す」と並んで「ワークツリーを削除」が加わります。lich が作成していないワークツリーや未コミットの変更があるワークツリーは、削除する前にダイアログで知らされます。

- **ネイティブウィンドウのターミナルが、ポインターの下のセルを正しく扱うようになりました。** クリック、ドラッグ選択、リンク、マウスを追跡するプログラムのいずれも、ターミナルのパディング分ずれた位置のポインターを読み取っていたため、実際に指しているセルの右下のセルが対象になっていました。スケーリングされたディスプレイでは、そのずれはほぼセル 1 つ分でした。
- **ネイティブウィンドウのターミナルが絵文字を描画するようになりました。** Noto Color Emoji などのカラー絵文字フォントは、各絵文字をアウトラインではなく画像として保持しています。ターミナルはアウトラインしか描画しなかったため、すべての絵文字が空白になっていました。現在は 2 セル幅のカラーで描画されます。
- **ネイティブウィンドウのファイルツリーが、ファイルごとの言語アイコンを表示するようになりました。** これまではどのファイルも同じ無地のファイルアイコンでしたが、ブラウザウィンドウと同じアイコンが付きます。
- **エージェントが開いたプルリクエストが、ターンの終了時にカードへ表示されるようになりました。** バッジはブランチまたは最後のコミットが動いたときにしか再確認されず、プルリクエストを開いてもどちらも動かないため、ウィンドウのフォーカスが外れて戻るまで待たされていました。
- **Windows でネイティブウィンドウが開くようになりました。** フォントの検索に Windows には含まれない fontconfig を使っていたため、起動時に閉じてしまい、lich はウェブウィンドウに切り替わっていました。Windows ではインストール済みのフォントを自前で見つけるようになり、ターミナルの既定は Cascadia Mono または Consolas、設定のフォントピッカーにも一覧表示されます。
- **ライトテーマとダークテーマを切り替えてもネイティブウィンドウがフリーズしなくなりました。** Claude Code のように、ターミナルの配色に追従するセッションへ、ウィンドウがまだターミナルを保持している間に変更が通知されていたため、ウィンドウがハングして閉じていました。
