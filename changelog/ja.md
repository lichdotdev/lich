## [0.72.0] - 2026-10-19

### Changed

- ネイティブウィンドウのトップバーがタイトルバーになりました。システムのタイトルバーはなくなり、最小化・最大化・閉じるボタンは設定の隣に、Windows、GNOME、KDE と同じ見た目で、デスクトップが配置する側に表示されます。macOS ではトラフィックライトがトップバーに収まります。トップバーの空いている部分をドラッグするとウィンドウを移動でき、ダブルクリックすると最大化します。タイル型ウィンドウマネージャーでは独自の装飾がそのまま使われます。

### Fixed

- lich が応答前に終了したとき、`lich quit` が "EOF" で失敗しなくなりました。失われた応答を拒否とみなさず、ポートが閉じるのを待ちます。
- Wayland で、ネイティブウィンドウが別のテーマのカーソルを表示することがありましたが、デスクトップ自身のカーソルをそのテーマとサイズで表示するようになりました。最大のモニターよりスケールの小さいモニターで、ウィンドウに入ったときにカーソルが跳ねなくなりました。
- Linux で、ネイティブウィンドウが汎用アイコンの別アプリとしてドックに表示されていましたが、lich 自身のアイコンの下にまとまるようになりました。
- ネイティブウィンドウのレビューと pull request のファイルで、スクロールバーが表示中のファイルに合わせて伸び縮みしていましたが、スクロールしてもサイズが変わらなくなりました。ドラッグするとファイル単位ではなく diff 全体を均等に移動します。
